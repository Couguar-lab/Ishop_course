# Ishop_course

## Описание

Проект простого интернетЪ-магазина для обучения ООП, в том числе:
- обучение работе с классами

## Функциональность
- Содержит модуль *classes_prod* для создания используемых классов "Product" и "Категория":
  - "Product" содержит такие атрибуты как: "name", "description", "price", "quantity"
    - Добавлен наследующий класс "Smartphone" с дополнительными атрибутами: "efficiency", "model", "memory", "color"
    - Добавлен наследующий класс "LawnGrass" с дополнительными атрибутами: "country", "germination_period", "color"
  - "Category" содержит такие атрибуты как: "name", "description", "products" (список), "category_count" (атрибут считает количество категорий), "product_count" (атрибут считает количество продуктов в категории)
- Модуль *data_loader* содержит функцию загрузки данных из json-файла. расположенного в директории data
- Пакет *tests* содержит модуль с фикстурами, а также модули для тестирования реализованного функционала
- Код проверяется при помощи линтеров isort, black, mypy, flack8

## Установка

1. Клонируйте репозиторий:
```
git clone git@github.com:Couguar-lab/Ishop_course.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
